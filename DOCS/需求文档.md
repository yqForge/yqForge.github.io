# Personal Portfolio / Digital Business Card

## 1. 项目定位

我要制作一个部署在 GitHub Pages 上的个人主页，用于承担个人数字名片和个人品牌主页的作用。

网站主要服务三个场景：

1. 考研复试 / 学术交流
2. 软件开发岗位求职 / 面试
3. 软件项目 / AI 应用 / 技术服务商务合作

网站不是传统意义上的简历网站，也不是单纯的 GitHub README，而是一个长期维护的个人 Portfolio。

核心目标：

> 让第一次访问网站的人，在 30 秒内理解“我是谁、现在做什么、做过什么、擅长什么、未来在探索什么，以及如何联系我”。

网站应该突出：

* 真实工程经历
* 项目成果
* 技术能力
* 持续学习
* 开源 / GitHub
* 清晰、克制、专业的个人形象

不要做成炫技型程序员主页，也不要做成传统企业官网。

---

# 2. 核心设计方向

整体风格：

> Minimal · Engineering · Professional · Personal · Modern

参考方向：

* GitHub Profile
* Linear
* Vercel
* Raycast
* 少量 Apple / Stripe 风格的留白和排版
* 稍微加入工程师 / Terminal / Code 的视觉语言

设计关键词：

* 干净
* 克制
* 高级
* 有工程感
* 有个人特色
* 信息层级清晰
* 不浮夸
* 不堆砌动画

避免：

* 大量 3D
* 粒子背景
* 鼠标跟随特效
* 满屏代码雨
* 过多渐变
* 大量彩色 Tech Logo
* 很重的滚动动画
* 自动播放背景音乐
* 巨大的“程序员”标签

核心原则：

> 内容可信度 > 视觉特效
