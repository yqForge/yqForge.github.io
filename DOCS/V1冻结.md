## 1. 定位

做一个部署在 GitHub Pages 上的个人名片站。

V1 只做一件事：让第一次访问的人在 30 秒内知道「我是谁、现在做什么、做过什么、怎么联系我」。

服务场景包括考研复试、求职面试、项目咨询，但不为三类访客各写一套文案。首页按「个人能力与项目」组织，合作入口只在 Contact 做轻量引导。

核心原则：

- 内容可信度 > 视觉特效
- 只写能讲清楚的事实
- 没有证据的能力不上首页主标题
- 公司名、教育经历、简历默认不上线

风格：

> Minimal · Engineering · Professional · Personal · Modern

参考：GitHub Profile、Linear、Vercel、少量留白排版。不要炫技（粒子、3D、代码雨、自动背景音乐、巨大「程序员」标签）。

## 10. 视觉与交互

- 大量留白、强排版、中等圆角、细边框、微弱阴影
- 黑 / 白 / 灰为主，一个低饱和 Accent（蓝 / 靛 / 紫择一）
- 支持 Light / Dark，默认跟随系统，顶部提供切换
- 动效仅限轻量 Fade / Hover / 锚点滚动；实现 `prefers-reduced-motion`
- 响应式：Desktop / Tablet / Mobile 分开处理，不只缩小桌面版
- 测试宽度：1440、1280、1024、768、390、375

## 11. 技术实现

- Astro + TypeScript + Tailwind CSS
- Markdown / MDX（V1 可先不用文章）
- Lucide Icons
- GitHub Actions → GitHub Pages
- 纯静态，无后端、无数据库、无登录

数据与 UI 解耦：

```
src/data/profile.ts
src/data/experience.ts
src/data/projects.ts
src/data/skills.ts
```

修改个人信息只改 data，不改页面结构。

禁止构建期强依赖 GitHub API。GitHub 信息写进配置。

SEO 最低集：title、description、og、favicon、robots.txt、sitemap.xml。  
title 示例：`YQ — 软件工程师 · Android Framework`

验收命令：`npm run build` 必须成功；`git push` 后自动发布。
